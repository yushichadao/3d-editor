# 立方·三维图形设计工坊

基于 Three.js 的 3D/2D 场景编辑器，支持图形创建、画笔绘制、橡皮擦除、对象变换、文本/图片添加、颜色记忆、场景导入导出等功能。

## 在线体验

- GitHub Pages: https://yushichadao.github.io/3d-editor/
- Gitee 镜像: https://gitee.com/yushichadao/3d-editor

## 功能特性

### 图形对象

- **3D 图形（20 种）**：立方体、球体、圆柱、圆锥、圆环、纽结、正二十面体、正八面体、正十二面体、胶囊、正四棱锥、正三棱柱、管道、回转体、正四面体、桶状体、半球、螺旋环、正八棱柱、立体星
- **2D 图形（20 种）**：正方形、圆形、正三角形、星形、正六边形、心形、正五边形、正八边形、椭圆、平行四边形、梯形、菱形、直角三角形、箭头、月牙、半圆、圆环、十字、闪电、水滴
- **文本对象**：可编辑文字内容、字号、颜色，朝向仅水平旋转
- **图片对象**：支持上传图片贴附到 3D 平面

### 绘制工具

- **3D 画笔**：在任意 3D 表面绘制立体线条，跟随表面法线
- **2D 画笔**：在地面平面绘制平面线条
- **橡皮擦**：擦除画笔线条，支持按半径检测、曲线分割与裁剪

### 颜色与外观

- **颜色记忆系统**：5 类对象（2D 画笔、3D 画笔、文本、2D 图形、3D 图形）颜色独立记忆
  - 画笔/文本默认黑色，图形默认白色
  - 刷新页面恢复默认，导出/导入保存颜色记忆
- **花纹系统**：图形对象支持 12 种花纹（纯色、方格、条纹、圆点、渐变、砖墙、斜纹、波浪、点阵、交叉、网格、螺纹），花纹预览跟随对象颜色实时更新
- **贴图功能**：图形对象支持图片贴图（与花纹互斥）
- **透明度调节**：每个对象可独立设置透明度
- **自定义颜色**：HSV 颜色选择器，支持无颜色（透明）模式
- **画笔限制**：画笔对象不显示花纹/贴图栏（仅支持纯色）

### 变换与编辑

- **平移/旋转/缩放**：支持单对象和多对象整体变换
- **框选**：拖拽框选多个对象
- **复制/粘贴/克隆**：剪贴板支持跨场景复制
- **撤销/重做**：完整历史栈，无限制步数
- **属性面板**：实时编辑位置、旋转、缩放、透明度等参数

### 视角与场景

- **四种预设视角**：透视、顶视、前视、侧视（自动适配所有对象包围盒）
- **坐标轴/网格线**：可独立切换显示；网格从坐标系原点（三条坐标轴与 12 个网格面的共同交点）对称延伸，覆盖全部对象、幽灵预览、画笔绘制中笔迹、橡皮擦命中点；画笔对象按Group内全部子mesh（含厚度边距）逐一遍历计算真实世界坐标；单元固定为 1.5，原点与坐标轴仅位于网格边缘（不穿过单位网格内部）；网格延展与收缩灵敏度一致，画笔保存、橡皮擦除后按最新对象边界实时伸缩
- **基准参考平面**：坐标轴与网格线同时隐藏时，自动显示淡色三面基准平面，辅助定位 3 个基准面
- **场景导入导出**：JSON 格式，包含对象数据、相机视角、颜色记忆
- **截图功能**：导出当前画面为图片

### 界面

- 移动端自适应布局，支持触摸操作
- 左侧面板：图形选择、工具栏
- 右侧面板：属性编辑、变换模式
- 顶部工具栏：新建、撤销重做、复制粘贴、导入导出、截图

## 本地开发

```bash
# 方式一：Node.js 服务器
node server.js
# 打开 http://127.0.0.1:8090/

# 方式二：PowerShell 服务器
powershell -ExecutionPolicy Bypass -File server.ps1
# 打开 http://localhost:9000/
```

无需安装依赖，Three.js 以本地文件形式引入（`./three/` 目录）。

## 技术栈

- **Three.js**：3D 渲染引擎（本地 `./three/` 目录，ES Module）
- **原生 JavaScript**：无框架依赖，ES Module 语法
- **HTML/CSS**：单文件应用，移动端适配

## 属性面板说明

### 坐标与变换

- **横坐标 X** / **纵坐标 Y** / **竖坐标 Z**：对象在场景中的位置
- **水平旋转** / **垂直旋转** / **侧向旋转**：对象三轴旋转角度
- **等比缩放**：统一缩放比例
- **透明度**：对象不透明度（0.1~1.0）

### 尺寸命名规范

- **3D 图形**：长度 L、宽度 W、高度 H
- **2D 图形**：长度 L、宽度 W
- **图片对象**：长度 L、宽度 W

### 多选行为

- 多选时变换作为整体操作
- 若包含画笔/文本/图片，自动隐藏花纹/贴图栏并提示
- 若包含图片或带贴图的图形，自动隐藏颜色栏并提示
- 仅全部对象支持某功能时才显示对应栏
