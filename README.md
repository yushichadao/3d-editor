# 立方 · 三维设计工坊

一款运行在浏览器里的纯前端 3D 编辑器。无需安装、无需登录，打开网页即可搭建三维场景、绘制立体笔迹、添加文字与图片。

- 在线地址：https://yushichadao.github.io/3d-editor/
- 项目仓库：https://github.com/yushichadao/3d-editor
- 技术栈：Three.js + 原生 JavaScript（单文件应用，零构建依赖）

---

## 它能做什么

- **图形库**：20 种 3D 立体图形 + 20 种 2D 平面图形，点击即可放置到地面。
- **自由变换**：平移 / 旋转 / 缩放，支持任意轴单独调整或开启等比缩放锁整体缩放；多选与框选。
- **上色与贴图**：27 种预设色、HEX 自定义、HSV 取色器、屏幕取色（吸管）、12 种花纹、本地图片贴图、不透明度调节。
- **画笔**：2D 画笔在地面作画，3D 画笔在空间中绘制立体管道，支持直线约束与球帽封口。
- **橡皮擦**：整对象删除，或开启局部擦除只抹掉 2D 笔迹的某一段。
- **文本与图片**：在场景中添加 3D 文字（8 种字体 / 字号 / 粗细 / 横竖排）与平面图片。
- **视角系统**：透视 + 顶 / 底 / 前 / 后 / 左 / 右 共 7 种预设视角，鼠标 / 触摸自由观察。
- **文件管理**：场景导出 / 导入 JSON、一键截图 PNG、撤销 / 重做、复制 / 粘贴 / 克隆。
- **便签**：阅读「使用说明书」时可在正文划线添加便签，并生成可悬浮的**便签窗口**；删除操作均通过自定义确认弹窗（兼容全屏模式）二次确认。
- **多语言**：界面支持 简体中文 / English / 日本語 / 繁體中文；「使用说明书」亦提供对应语言版本。

## 本地运行

本项目是纯静态页面，任选一种方式启动本地服务器即可：

```bash
# 方式一：使用项目自带脚本（Windows PowerShell）
./server.ps1

# 方式二：使用 Node 静态服务器
node scripts/_serve.mjs 8090

# 方式三：任意静态服务器
npx serve .
```

启动后浏览器访问提示的本地地址（默认 `http://localhost:8090`）。

## 坐标系约定

场景采用 **Z 轴向上** 的约定（以下轴名与颜色均指页面上显示的标注）：

| 轴 | 颜色 | 方向 |
| --- | --- | --- |
| X | 蓝 | 前后（深度） |
| Y | 红 | 左右 |
| Z | 绿 | 上下（高度） |

地面是由 X（前后）与 Y（左右）张成的水平基准面（高度轴 Z = 0），对象放上去会自动「站」稳在地面之上。

> 注：底层 Three.js 实际为 Y-up，界面通过重映射轴标签向用户呈现上述「Z 轴向上 / X蓝·Y红·Z绿」体系，便于初学者建立直觉。
