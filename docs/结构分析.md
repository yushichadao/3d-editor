# 项目结构分析

> 本文梳理 `index.html`（约 9900 行的单文件应用，HTML + CSS + JS 全部内联）的整体结构，重点说明各区域职责与关键代码位置，便于二次开发与定位问题。所有行号均依据当前代码实际位置。

---

## 一、文件总体划分

| 区间 | 内容 |
| --- | --- |
| `<head>`（约 L1–L1000） | 全部 CSS：主题变量、布局、控件、面板、模态框、响应式 |
| `<body>` 结构（约 L1000–L1200） | 加载层、画布、顶栏、左面板、右面板、底栏、取色器弹窗 |
| `<script type="module">`（约 L1200–L9959） | 全部逻辑：初始化 → 工具函数 → 模块 → 事件绑定 → 动画循环 |

坐标系采用 **Y 轴向上**：X 红（左右）、Y 绿（上下 / 高度）、Z 蓝（前后 / 深度），地面为 XZ 平面（y = 0）。

---

## 二、HTML 与样式要点

| 区块 | 说明 |
| --- | --- |
| 全局变量 | 主题色系、圆角、阴影、尺寸等 `--` 开头的 CSS 变量 |
| 画布 | `#canvas-wrap`、`#three-canvas` 的尺寸与定位 |
| 顶栏 | 品牌区 + 文件 / 编辑 / 显示三类功能按钮 |
| 面板 | 左 / 右抽屉、折叠按钮（窄屏自动收起） |
| 图形网格 | 形状按钮的图标网格与悬停态 |
| 控件 | 滑块、开关、颜色行等通用控件 |
| 底栏 | 7 个视角切换按钮 |
| 取色器 | 屏幕取色放大预览 + HSV 面板 + 色相条 + HEX / RGB 输入 |

左侧工具按钮（HTML 约 L670–713）：选择 / 变换、3D 画笔、2D 画笔、橡皮擦、添加文本、添加图片。3D / 2D 图形按钮由 `buildShapeGrid()` 动态生成。

## 四、整体职责

- **HTML / CSS**：以「顶栏 + 左面板 + 画布 + 右面板 + 底栏」组织界面，配取色弹窗与响应式样式，覆盖形状库、工具、属性、颜色、贴图、文本、画笔、橡皮擦、快捷键等完整能力。
- **JavaScript**：以「全局状态 + 顶层函数」分治实现，从场景初始化、几何 / 图形工厂、对象创建、选择变换、属性同步、历史记录，到画笔 / 橡皮擦绘制、取色、复制粘贴、视角切换、网格与动画循环，形成完整的三维编辑闭环。全部函数均为顶层 `function` 声明，便于检索（见 `函数表.md`）。

> 如需逐函数索引（函数名 + 行号 + 职责），见 `函数表.md`。
