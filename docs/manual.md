## 1. 入门：第一次使用

### 1.1 打开编辑器

1. 在浏览器地址栏输入 `https://yushichadao.github.io/3d-editor/` 访问
2. 页面加载后你会看到三栏布局：
   - **左侧栏**：3D/2D 图形库与工具
   - **中央画布**：3D 场景编辑区
   - **右侧栏**：属性面板与快捷键说明

### 1.2 界面认识

| 区域 | 说明 |
|------|------|
| 顶部栏 | 新建、导入、导出、截图、撤销、重做、复制、粘贴、克隆、清空、坐标轴、网格面、全屏 |
| 左侧栏 | 3D 图形、2D 图形、工具、变换模式 |
| 画布 | 3D 场景，带坐标轴（X蓝/Y红/Z黄）与网格 |
| 右侧栏 | 属性、颜色、贴图、文本、画笔、橡皮擦、快捷键 |
| 底部栏 | 7 种视角切换按钮 |

### 1.3 坐标系说明

本编辑器采用 **Z-up** 坐标系（屏幕显示）：

- **X 轴**（横坐标）：前为正，后为负（蓝色箭头）
- **Y 轴**（纵坐标）：左为正，右为负（红色箭头）
- **Z 轴**（竖坐标）：上为正，下为负（黄色箭头）

> 提示：坐标轴箭头尖端的文字标签会循环显示（X/Y/Z），请以**箭头颜色**为准判断轴向。

## 2. 基础：创建与选择对象

### 2.1 创建 3D 图形

左侧栏 **3D 图形** 面板提供两种添加方式：

**点击添加**：
1. 点击想要的图形按钮（如"立方体"）
2. 图形立即出现在**视野中心**对应的地面位置，大小为默认值
3. 自动切换到"选择/变换"模式

**拖动添加**：
1. 在图形按钮上**按住左键**不放，拖到画布上
2. 鼠标移动时会出现半透明的**幽灵预览**，实时跟随光标
3. **拖拽距离越远，对象越大**
4. **松开左键**完成放置

> 拖动添加适合快速控制初始大小，点击添加适合精确放置到视野中央。松开时均自动切换到"选择/变换"模式。

### 2.2 创建 2D 图形

左侧栏 **2D 图形** 面板同样支持**点击添加**与**拖动添加**两种方式，操作与 3D 图形一致。

> 2D 图形是平面形状，默认贴在地面上。

### 2.3 选择对象

| 操作 | 方式 |
|------|------|
| 单选 | 左键点击对象 |
| 多选 | Shift + 左键点击多个对象 |
| 框选 | 在空白处按住左键拖动画出矩形 |
| 全选 | Ctrl + A |
| 取消选择 | 点击空白处 或 Esc |

### 2.4 删除对象

- 选中对象后按 **Del** 或 **Backspace** 键
- 或在右侧栏 **删除** 面板点击"删除选中对象"按钮

## 3. 变换：移动、旋转、缩放

### 3.1 切换变换模式

在左侧栏 **变换模式** 面板：

| 模式 | 按钮 | 快捷操作 |
|------|------|---------|
| 平移 | ⇔ 平移 | 直接拖拽对象 |
| 旋转 | ↻ 旋转 | 拖拽对象绕轴旋转 |
| 缩放 | ⤢ 缩放 | 拖拽改变大小 |

> 选中对象后，对象上会出现彩色变换控件（箭头/圆环/方块），直接拖拽控件即可。

### 3.2 精确变换（属性面板）

选中对象后，右侧栏 **属性** 面板显示：

| 属性 | 范围 | 说明 |
|------|------|------|
| 横坐标 X | -50 ~ 50 | 沿 X 轴位置 |
| 纵坐标 Y | -50 ~ 50 | 沿 Y 轴位置 |
| 竖坐标 Z | -50 ~ 50 | 沿 Z 轴位置 |
| 水平旋转 | -180° ~ 180° | 绕 Z 轴旋转 |
| 垂直旋转 | -180° ~ 180° | 绕 X 轴旋转 |
| 侧向旋转 | -180° ~ 180° | 绕 Y 轴旋转 |
| 等比缩放 | 0.1 ~ 5 | 整体大小 |
| 透明度 | 0.1 ~ 1.0 | 不透明度 |

每个属性都有**滑动条**和**数字输入框**，可拖动滑块或直接输入数值。

> **滑动条与数字输入框的关系**：滑动条提供的只是**建议范围**，方便快速调节。如果需要输入滑动条范围以外的数值，在保证输入的数值合法的情况下（旋转角度限定 -180 ~ 180），可通过**数字输入框**直接输入。

### 3.3 多选变换

- Shift+点击选中多个对象后，变换控件作用于**整体中心**
- 多选时**禁止缩放**（防止比例混乱），会给出提示

### 3.4 等比缩放开关

变换模式面板下方有"**等比缩放**"开关：
- 开启（默认）：缩放时三轴等比例
- 关闭：可单独缩放某一轴

## 4. 外观：颜色、花纹、贴图

### 4.1 设置颜色

1. 选中对象
2. 右侧栏 **颜色** 面板显示颜色预设
3. 点击预设色块即可应用
4. 点击"**自定义颜色**"打开颜色拾取器：
   - 在 SV 面板点击选择饱和度/明度
   - 在色相条选择色相
   - 可直接输入 HEX/RGB 值
   - 点击"确定"应用

> **颜色记忆**：每种对象类型（3D/2D/文本/画笔）会记住上次使用的颜色，下次创建时自动使用。

### 4.2 设置花纹

1. 选中对象
2. 右侧栏 **颜色** 面板下方有 12 种花纹预设：
   - 纯色、方格、条纹、圆点、渐变、砖墙、斜纹、波浪、点阵、交叉、网格、螺纹
3. 点击花纹预览即可应用

### 4.3 添加图片贴图

1. 选中对象（非文本）
2. 右侧栏 **贴图** 面板点击"**应用图片贴图**"
3. 选择本地图片文件
4. 图片会自动应用到对象表面

### 4.4 清除贴图

点击"**清除贴图**"按钮移除图片贴图与花纹，恢复纯色。

### 4.5 无颜色模式

颜色预设中有一个特殊的 **×**（无颜色）选项：
- 适用于形状和画笔
- 显示为白色半透明效果
- 透明度由系统强制控制

## 5. 文本与图片

### 5.1 添加文本

1. 左侧栏 **工具** 面板点击"**添加文本**"
2. 在画布地面点击放置位置
3. 弹出文本输入框，输入文字
4. 按确定或 Ctrl+Enter 确认

### 5.2 编辑文本

| 操作 | 方式 |
|------|------|
| 修改内容 | 双击文本对象进入编辑 |
| 字体 | 右侧栏 **文本** 面板选择 |
| 字号 | 滑动条调节（24-220） |
| 粗细 | 切换"细体/粗体"按钮 |
| 排列方向 | 切换"横排/竖排"按钮 |

> 字号数字输入框**禁止输入正负号**，只能输入数字。

### 5.3 添加图片对象

1. 左侧栏 **工具** 面板点击"**添加图片**"
2. 选择本地图片
3. 在地面点击放置
4. 选中后可在属性面板调节长宽

## 6. 画笔工具

### 6.1 3D 画笔

1. 左侧栏 **工具** 面板点击"**3D 画笔**"
2. 在画布中**按住左键**开始绘制
3. 鼠标在 3D 空间中移动，笔迹会沿空间路径生成
4. **松开左键**完成一笔

> 3D 画笔会在按下时锁定一个参考平面，整个笔画在此平面内绘制。

### 6.2 2D 画笔

1. 左侧栏 **工具** 面板点击"**2D 画笔**"
2. 按住左键在地面绘制
3. 笔迹是贴在地面上的平面图形
4. 2D 画笔**双面可见**

### 6.3 画笔属性

在右侧栏 **画笔** 面板可调节：

| 属性 | 说明 |
|------|------|
| 颜色 | 同对象颜色，支持预设与自定义 |
| 粗细 | 0.05 ~ 3.0 |
| 透明度 | 0.1 ~ 1.0 |
| 间隔 | 0.02 ~ 0.5（点间距） |

### 6.4 Ctrl+画笔约束直线

- 绘制时**按住 Ctrl** 键，笔画会被约束为直线
- **一笔只锁定一次方向**：首次按 Ctrl 时根据移动方向锁定最强轴向（X/Y/Z），后续沿此方向约束
- 松开 Ctrl 可恢复自由绘制（但方向已锁定到本笔结束）

## 9. 编辑操作

### 9.1 撤销与重做

| 操作 | 快捷键 | 按钮 |
|------|--------|------|
| 撤销 | Ctrl + Z | 顶部栏 ↶ |
| 重做 | Ctrl + Y | 顶部栏 ↷ |

> 支持最多 60 步历史。所有操作（创建、变换、删除、贴图等）均可撤销。

### 9.2 复制与粘贴

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 复制 | Ctrl + C | 将选中对象存入剪贴板 |
| 粘贴 | Ctrl + V | 将剪贴板中的对象粘贴到**视野中心** |
| 克隆 | Ctrl + D | 等于复制+粘贴，新对象出现在**原对象附近**（偏移一点，避免重叠） |

> **复制/粘贴与克隆的区别**：
> - **复制/粘贴**：分两步操作。粘贴时新对象出现在**视野中心**，适合将对象搬到当前视角焦点处。
> - **克隆**：一步到位。新对象出现在**原对象附近**（小幅偏移），适合在原地快速复制。

### 9.3 全选与删除

| 操作 | 快捷键 |
|------|--------|
| 全选 | Ctrl + A |
| 删除选中 | Del / Backspace |
| 清空场景 | Ctrl + Del / Ctrl + Backspace |

> 清空场景前会弹出确认框，防止误操作。

## 10. 场景管理

### 10.1 新建场景

- 顶部栏点击"**新建**"（Ctrl + N）
- 会清空当前场景（有对象时弹出确认框）

### 10.2 导出场景

1. 顶部栏点击"**导出**"（Ctrl + S）
2. 自动下载 `.json` 格式场景文件
3. 文件包含所有对象数据、颜色记忆、相机视角

### 10.3 导入场景

1. 顶部栏点击"**导入**"（Ctrl + O）
2. 选择之前导出的 `.json` 文件
3. 场景恢复（含对象、颜色、视角）

### 10.4 截图导出

1. 顶部栏点击"**截图**"（Ctrl + P）
2. 自动下载 `.png` 格式图片
3. 截图包含当前画面所有可见内容

### 10.5 坐标轴与网格面

| 按钮 | 功能 |
|------|------|
| 📐 坐标轴 | 显示/隐藏坐标轴箭头与标签 |
| 🔲 网格面 | 显示/隐藏三个网格面（地面/后墙/侧墙） |

> 关闭网格面时仍保留白色地面参考面用于定位。

## 12. 精通：高级技巧

### 12.1 快速搭建场景

1. 先用 3D 图形摆出主体结构
2. 用 2D 画笔添加地面装饰
3. 用 3D 画笔添加空间线条
4. 用文本添加标注
5. 用图片贴图丰富材质

### 12.2 多选批量操作

1. Shift+点击多个对象
2. 使用键盘快捷键批量平移/旋转
3. 多选时变换控件绕整体中心操作
4. 用框选快速选中一片区域

### 12.3 画笔直线约束

- 绘制时按 Ctrl 约束直线
- 首次按 Ctrl 会锁定最强轴向
- 适合绘制规则几何线条

### 12.4 局部擦除画笔

1. 切换到橡皮擦的"**局部擦除**"模式
2. 调小橡皮尺寸
3. 精细擦除画笔的某一段
4. 画笔会自动分段重建

### 12.5 颜色记忆机制

- 每种对象类型独立记忆颜色
- 3D/2D/文本/画笔2D/画笔3D 各有独立记忆
- 创建新对象时自动使用上次的颜色

### 12.6 视角技巧

- 顶视 + 正视组合：精确对齐位置
- 透视视角拖拽：自由旋转查看
- 缩放到极近：看清极小对象（支持放大到一个网格单元的 1/10）

### 12.7 场景导出与备份

- 定期导出 JSON 备份
- JSON 文件可版本管理
- 可作为模板复用

### 12.8 性能优化

- 对象过多时关闭网格面提升流畅度
- 复杂画笔笔画可用局部擦除简化
- 截图前隐藏不需要的辅助元素

## 常见问题

### Q: 为什么多选时不能缩放？
A: 多选缩放会导致各对象比例混乱，系统禁止此操作并给出提示。请单选后缩放。

### Q: 2D 画笔只能看到一面？
A: 已修复。2D 画笔现在双面可见。

### Q: 撤销时第一次没反应？

### Q: 如何精确控制位置？
A: 使用右侧栏属性面板的数字输入框直接输入坐标值。

### Q: 画笔的 Ctrl 直线约束为什么方向变了？
A: 一笔只锁定一次方向，首次按 Ctrl 时根据移动方向自动判断轴向，之后不可更改。

### Q: 导出的 JSON 文件可以编辑吗？
A: 可以，JSON 是文本格式，可用任意文本编辑器修改，但建议保留备份。
