# 立方·三维设计工坊

> 一个基于 Three.js 的纯前端 3D/2D 场景编辑器，支持2D图形/3D图形/文本/图片创建、2D/3D画笔绘制、3D图形表面图片贴图、变换操作、撤销重做与场景导入导出。所有运算与渲染均在浏览器本地完成，不上传任何用户数据。

## 核心特性

- **3D 图形库**：内置立方体、球体、圆柱、圆锥、圆环、纽结、正二十面体、正八面体、正十二面体、胶囊、正四棱锥、正三棱柱、管道、回转体、正四面体、筒状体、半球、螺旋环、正八棱柱、立体星 20 种 3D 参数化图形，每种均支持参数调节；支持**点击添加**（放置到视野中心）与**拖动添加**（拖拽控制位置）两种创建方式
- **2D 图形库**：内置正方形、圆形、三角形、星形、六边形、心形、正五边形、正八边形、椭圆、平行四边形、梯形、菱形、直角三角形、箭头、月牙、半圆、环形、十字、闪电、水滴 20 种 2D 形状；同样支持点击添加与拖动添加
- **画笔工具**：支持 3D 空间画笔与 2D 平面画笔，实时平滑曲线生成，支持 Ctrl+拖动约束直线
- **橡皮擦**：对象删除模式与局部擦除模式，支持 2D/3D 画笔的精确擦除
- **文本与图片**：可添加自定义文本（支持字体、字号、粗细、横竖排）与图片贴图
- **变换操作**：平移、旋转、缩放三种模式，支持单选与多选整体变换；属性面板滑动条提供建议范围，数字输入框可输入范围外合法数值（旋转限定 -180~180）
- **编辑操作**：复制/粘贴（新对象到视野中心）与克隆（新对象在原对象附近）两种快速复制方式
- **材质与花纹**：12 种程序化花纹（方格、条纹、圆点、渐变、砖墙等），支持透明度与颜色记忆
- **历史记录**：完整的撤销/重做机制，支持 60 步历史
- **场景管理**：JSON 格式导入导出，PNG 截图导出
- **视角控制**：7 种预设视角（透视/顶/底/正/后/左/右），360° 自由旋转
- **键盘快捷键**：完整的快捷键体系，支持平移、旋转、缩放、功能键与组合键
- **动态网格**：网格面根据对象范围自动扩展，始终保持原点位于网格交点

## 技术栈

| 项目 | 说明 |
|------|------|
| 核心库 | Three.js r160+（ES Module） |
| 渲染器 | WebGLRenderer（抗锯齿、阴影） |
| 控制器 | OrbitControls + TransformControls |
| 运行环境 | 现代浏览器（支持 ES Module） |
| 部署 | 静态文件，可直接用任意 HTTP 服务器托管 |

## 项目结构

```

├── index.html              # 主文件（HTML+CSS+JS 全部集成）
├── server.js               # Node.js 静态文件服务器
├── server.ps1              # PowerShell 静态文件服务器
├── package.json            # 项目配置
├── vercel.json             # Vercel 部署配置
├── .nojekyll               # 禁用 GitHub Pages 的 Jekyll 处理
├── LICENSE                 # 开源协议

    ├── three.module.js
    └── examples/jsm/controls/
        ├── OrbitControls.js
        └── TransformControls.js
```

## 坐标系说明

本编辑器采用 **Z-up** 坐标系（UI 显示），与 Three.js 内部 Y-up 的映射关系：

| UI 坐标 | Three.js 坐标 | 方向 |
|---------|--------------|------|
| X（横坐标） | X | 右为正 |
| Y（纵坐标） | Z | 前为正 |
| Z（竖坐标） | Y | 上为正 |

## 键盘快捷键速查

| 类别 | 快捷键 | 功能 |
|------|--------|------|
| 平移 | ↓/↑、→/←、PgUp/PgDn | 沿 X/Y/Z 轴平移 0.1 单位 |
| 旋转 | A/D、W/S、E/Q | 绕 Z/Y/X 轴旋转 5° |
| 缩放 | + / - | 放大/缩小 5% |
| 功能 | Esc、F11、Del/Backspace | 取消、全屏、删除 |
| 组合 | Shift+方向、Shift+字母、Ctrl+A/Z/Y/C/V/D 等 | 大步长变换与编辑操作 |

详细快捷键说明见 [使用说明书](docs/manual.md#键盘快捷键)。
