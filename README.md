# 立方·三维设计工坊 (3D Editor)

> 一个纯前端的 3D / 2D 场景编辑器，基于 HTML / CSS / JavaScript 与 Three.js 构建，无需后端依赖即可在浏览器中完成三维建模、二维绘图与场景编排。

- **作者**：yushichadao
- **AI 辅助**：使用 [TRAE](https://trae.ai/) 工具的 AI 能力辅助生成
- **最后更新**：2026-08-02
- **技术栈**：纯前端 HTML / CSS / JavaScript + Three.js
- **本地服务器**：Node.js（`server.js`，端口 `8090`）

---

## 项目简介

「立方·三维设计工坊」是一款运行于浏览器端的轻量级三维 / 二维场景编辑器。项目不依赖任何后端服务，所有渲染、交互、文件读写均在浏览器本地完成，仅通过一个 Node.js 静态服务器提供本地访问入口。

编辑器内置丰富的 3D 几何体、2D 图形、画笔与文本工具，支持对象的平移、旋转、缩放、复制、克隆、删除等完整操作链路，并提供多视角切换、颜色与花纹系统、无限制撤销 / 重做、JSON 导入导出与 PNG 截图等功能，同时针对桌面、平板、手机三档屏幕做了响应式适配与触摸手势支持。

## 主要功能

### 1. 3D 图形（20 种）
立方体、球体、圆柱、圆锥、圆环、环面纽结、二十面体、八面体、十二面体、胶囊体、四棱锥、三棱柱、管道、旋转体、四面体、桶形、穹顶、螺旋、八角柱、3D 星形。

### 2. 2D 图形（20 种）
正方形、圆形、三角形、五角星、六边形、心形、五边形、八边形、椭圆、平行四边形、梯形、菱形、直角三角形、箭头、月牙、半圆、圆环、十字、闪电、水滴。

### 3. 画笔工具
- **2D 画笔**：在 XY 平面上自由绘制曲线。
- **3D 画笔**：在三维空间中绘制管道。
  - `Ctrl`：约束为直线
  - `Shift`：约束为直线

### 4. 橡皮擦
- **删除对象模式**：点击对象即删除。
- **2D 笔迹局部擦除模式**：通过复选框切换，可擦除 2D 笔迹的局部片段。

### 5. 文本工具
支持 8 种字体、横排 / 竖排排版、粗体 / 常规字重、字号调节。

### 6. 图片工具
上传本地图片，可作为对象贴图或作为独立对象置于场景中。

### 7. 对象操作
选择（单选 / 多选 / 框选）、平移、旋转、缩放、复制、克隆、删除。

### 8. 视角控制
- 7 种预设视角：透视、顶、底、正、后、左、右。
- 鼠标交互：旋转、平移、缩放。

### 9. 颜色系统
- 27 种预设颜色
- HSV 颜色选取器
- 12 种花纹贴图

### 10. 历史记录
撤销 / 重做，步数无限制。

### 11. 文件操作
新建场景、导入 JSON、导出 JSON、截图导出 PNG。

### 12. 网格系统
动态自适应网格、坐标轴显示、网格面显示。

### 13. 响应式设计
桌面 / 平板 / 手机三档自适应，支持触摸手势操作。

### 14. 键盘快捷键
完整的快捷键系统，覆盖：
- 平移快捷键
- 旋转快捷键
- 缩放快捷键
- 功能键
- `Ctrl` 组合键
- `Shift` 组合键

## 坐标系说明

本项目在 UI 显示上采用 **Z-up** 坐标系（便于直观地以「上下」对应 Z 轴），底层 Three.js 引擎则使用 **Y-up** 坐标系，二者在内部已完成转换。

| 轴 | 方向 | 颜色 |
| --- | --- | --- |
| X 轴 | 左右方向 | 红色 |
| Y 轴 | 前后方向 | 绿色 |
| Z 轴 | 上下方向 | 蓝色 |
